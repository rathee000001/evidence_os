# Project Study Packet v1

- projectStudyRunId
- projectSlug
- file inventory
- source map
- OCR summary
- PDF extraction summary
- Excel/CSV/Tableau summary
- code summary
- tool map
- skill map
- evidence map
- metrics found
- claim boundary draft
- resume bullet candidates
- interview prep notes
- chatbot answer-card candidates
- public-safe content candidates
- review status
