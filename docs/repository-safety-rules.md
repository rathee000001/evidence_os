# EvidenceOS Repository Safety Rules

D:\evidence_os is the clean app and GitHub repo.

D:\evidence_os_evidence_vault is the raw evidence vault and must not be committed.

Allowed in this repo:
- App code
- Approved JSON content
- Safe docs
- Safe manifests / tree files
- Public-ready assets only after approval

Not allowed in this repo:
- Raw PDFs
- Raw screenshots
- Raw cloned project repos
- Raw OCR
- Gemma drafts
- Private notes
- Local AI model files
- Job tracker files
- Recruiter replies
- Private evidence

Only approved public-safe summaries move into src/content.
